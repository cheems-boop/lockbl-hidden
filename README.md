# 越狱隐藏环境1.1
>该方案仅在 zygisknext + 月虹模块 + lsp +fusehide隐藏无效的状态下推荐使用
>目前该方案仅在OPace5u上测试表现为接近完美环境，因为OPace5u使用月虹的老方案表现为，Permission loophole 发现magisk运行痕迹 等多项报错
>如果以后模块的版本更新了，就不一定能达到这种效果
>还有，要认真观看，有一些细节必须遵守，该教程并不绝对，如果你能简化更好，可能存在漏洞，自己注意

---

## 以下是正文内容
1. 使用月虹提权/ghostlock，或其他方案提权ksu
2.  安装过程：
```
1. fusehide
2. neozygisk
3. lsp
4. HMA-oss(这个后来自己配置，该文章不会写)
```
3. 一次重启
>注意：如果重启以后发现lsp HMA激活失败则进行冷重启，然后在ksu右上角进行软重启，如果还是不行，则放弃此方案

4. 打开lsp，激活fusehide
>这里不需要重启，只需要来回，选择媒体疯狂的优化和强行停止，直到显示fusehide为止，如果怎么的也不行，可以软重启

5. 配置fusehide,具体步骤如下
```text
1. 点击配置
2. 点击右上角的设置
3. 将可见例外中的Android MT2删掉如果有
4. 右上角保存
```

6. 刷入`cq-uid-seccomp-0.2.1.zip`

7. 刷入月虹模块
>此过程，出现选择模式，选择搞机模式
>此过程，出现仅做基础配置相应的和下载lsp zygisknext选前者，具体表现为 音量下键

8. 刷入完成之后进行如下操作：
```text
1. 判断是否模块左下角出现了进入配置
2. 如果出现点击进入，然后选择过检测软重启，如果你不会配置HMA你可以选择它的配置，如果没有出现进入配置，看接下来
3..软重启进行第二步
```
>接下来的每一次重启全部使用，月虹的过检测软重启

## 补充：
>如果你刷不了月虹，也可以刷`免解刷我`代替，不过不推荐，刷完以后要用这个模块的执行重启，具体模块在春秋二群
